# Junteng Liu — Academic Homepage

Personal academic homepage for Junteng Liu, built with the Academic Pages Jekyll template.

## Pages

- [About](https://constraintsagebound.github.io/LJT-Homepage/) — personal details, research interests, education, research experience, skills, publications, awards, and contact information.
- [Publications](https://constraintsagebound.github.io/LJT-Homepage/publications/) — the complete publication list.

The About section also includes the complete publication list.

## Development and deployment

The Jekyll site is built and validated by GitHub Actions. To publish it, enable **Settings → Pages → GitHub Actions** in this repository; the included workflow will then deploy the site automatically.
